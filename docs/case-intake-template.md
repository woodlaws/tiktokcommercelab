# 성공사례 자료 수집 템플릿

이 문서는 공개 페이지에 연결되지 않는 내부 입력 양식입니다. 실제 사례를 공개하기 전에는 고객의 공개 동의와 증빙 범위를 반드시 확인합니다.

```json
{
  "브랜드명": "",
  "공개 가능 여부": false,
  "업종": "",
  "상품명": "",
  "프로젝트 기간": { "시작": "", "종료": "" },
  "고객의 기존 문제": "",
  "목표": [],
  "담당 업무": [],
  "방송 플랫폼": [],
  "사전 콘텐츠 수": null,
  "방송 횟수": null,
  "시청자 수": null,
  "최고 동시 시청자": null,
  "방송 매출": null,
  "판매 수량": null,
  "전환율": null,
  "광고비": null,
  "ROAS": null,
  "영상·사진": [],
  "고객 후기": "",
  "공개 가능한 증빙": [],
  "개인정보 또는 거래처 비공개 처리 여부": true
}
```

## 공개 전 확인

- 숫자의 기간, 단위, 광고비·환불 포함 여부를 함께 기록합니다.
- 고객명, 로고, 현장 사진, 영상, 후기마다 공개 동의를 따로 확인합니다.
- 확인되지 않은 수치와 식별 가능한 개인정보는 `cases-data.ts`에 입력하지 않습니다.
- 공개 가능한 자료가 모두 정리된 뒤 `status`를 `published`로 변경합니다.
